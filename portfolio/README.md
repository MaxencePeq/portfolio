# Portfolio — Maxence Pequeno

> Squelette à remplacer : capture d'écran, lien vers le site en ligne, et ce
> que le projet démontre.

## Stack

React 19 · TypeScript · Tailwind CSS 4 · Vite · React Router

## Développement

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # tsc -b && vite build
npm run lint
```

Avec Docker :

```bash
docker compose up dev
```
